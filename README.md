# ОРБИТА — СССР и космос

Интерактивная образовательная экспозиция о достижениях СССР в 1957–1991 годах. Исторический рассказ, навигация, 17 источников и режим выступления сохранены; графика переработана в Three.js.

## Возможности

- Земля с локальными картами NASA Blue Marble, облаками, атмосферным шейдером и направленным солнечным освещением.
- Настоящие 3D-Спутник и орбита в одной сцене с Землёй. Окклюзию определяет depth buffer, а не скрытие по условию.
- Четыре типа технических моделей: Спутник-1, Восток, Луна-9 и Венера-9. Вращение, плавная инерция, масштаб, привязанные к геометрии маркеры и доступные кнопки деталей.
- Закреплённая сцена пилотируемых полётов на широком экране. На телефоне модель расположена перед текстом и не перекрывает его.
- Лунные и венерианские миссии, Марс-3, сборка «Мира», технологии, проблемы, хронология и итоги.
- 13 этапов режима выступления; стрелки, PageUp/PageDown, Escape.
- Один общий WebGL canvas, отрисовка видимых сцен, отложенное создание моделей, ограниченный DPR и снижение разрешения при медленных кадрах. Учитывается prefers-reduced-motion.

Модели — авторские технические реконструкции, не фотограмметрия. Масштаб орбиты условный. Карты Земли — композитные изображения NASA, не погода 1957 года. Подробности: [источники графики и лицензии](assets/ATTRIBUTION.md).

## Запуск и сборка

Нужен Node.js 20+.

```sh
npm ci
npm run dev
```

После изменения исходников повторите сборку и обновите страницу.

```sh
npm run check
npm run build
npm run preview
```

`dev` и `preview` используют порт 4173. Для одновременной проверки: `PORT=4174 npm run preview`.

`dist/` содержит готовый статический сайт. `dist/Открыть-сайт.html` содержит встроенные скрипты, стили и текстуры — резервная автономная копия. Для просмотра 3D требуется WebGL; описание остаётся доступным при его отсутствии. Внешние исторические источники требуют интернета.

## Структура

- `index.html`, `app.js` — существующая экспозиция, исторический текст и интерактивы.
- `src/museum.js` — общий рендерер, Земля, управление, отрисовка, глубина и диагностика.
- `src/models.js` — геометрия аппаратов и пояснения деталей.
- `style.css` — композиция, адаптивность, доступность.
- `assets/` — локальные текстуры, лицензии и атрибуция.
- `build.mjs` — сборка esbuild и автономный HTML.
- `.github/workflows/pages.yml` — GitHub Actions: проверка, сборка, GitHub Pages.
- `Сценарий защиты.md`, `Проверка.md` — материалы для выступления и результаты проверки.

## Публикация

Репозиторий: https://github.com/Haist-PM/ussr-space

В Settings → Pages источником публикации выбирается GitHub Actions. Workflow «Publish educational site» публикует папку `dist` после изменения ветки `main`. Все пути относительные и поддерживают размещение в подпапке `/ussr-space/`.

## Диагностика

Параметр `?qa=1` открывает панель проверки: фаза орбиты, ракурсы, число кадров и завершённых оборотов, ресурсы и GPU-проверка перекрытия. На обычной ссылке панель отсутствует. GPU-аудит сравнивает число пикселей спутника с Землёй и без неё на 12 сочетаниях ракурса и фазы; рабочая сцена всегда использует настоящее тестирование глубины.

Перед защитой сохраните автономную копию, проверьте проектор, фамилии участников и отрепетируйте переходы. Схемы не следует называть фотографиями, посадку автомата — высадкой человека.
