# ОРБИТА — СССР и космос

Интерактивная образовательная экспозиция о достижениях СССР в 1957–1991 годах. Исторический рассказ, навигация, 17 источников и режим выступления сохранены; графика переработана в Three.js.

## Возможности пятого прохода

- Вертикальное путешествие: шесть закреплённых сцен, 24 последовательных текстовых этапа, спокойные разделы технологий, трудностей, хронологии и итогов. Миссии доступны без выбора вкладок.
- Полноценные текстурированные Земля, Луна, Венера и Марс. Локальные карты, боковой свет, тонкая атмосфера и граница дня и ночи.
- Спутник-1, «Восток», «Восход-2» со шлюзом, «Луна-9», «Луноход-1», «Венера-9», «Марс-3», «Салют-1» и советская конфигурация «Мира».
- Даты, подписи, ракурс и присоединение модулей вычисляются из текущей позиции прокрутки. Обратная прокрутка восстанавливает предыдущий этап.
- Мышь и стрелки вращают сам объект; поверхность планеты медленно вращается отдельно. После ручного поворота движение возобновляется плавно. Колесо всегда прокручивает страницу. На телефоне горизонтальное движение пальца вращает объект, вертикальное прокручивает страницу.
- Компактный возврат ракурса, глобальная пауза движения, режим выступления (30 этапов), источники и «Подробнее». На узком экране сцена закреплена над областью чтения.
- Один общий WebGL canvas, ленивое создание сцен и загрузка текстур, ограниченный и адаптивный DPR. При скрытой вкладке рендеринг приостанавливается; reduced motion отключает вращение, инерцию и декоративные движения.
- Локальный Manrope с кириллицей; автономный HTML включает шрифт и все текстуры.

Модели — авторские технические реконструкции, не фотограмметрия или CAD. Взаимные масштабы и скорость движения условны. Карты Земли — композитные изображения NASA, не погода 1957 года. Подробности: [источники графики и лицензии](assets/ATTRIBUTION.md).

## Исправления пятого прохода

Фон всех основных поверхностей снова `#070b10`. Перетаскивание и инерция следуют движению курсора; поворот вычисляется в осях экрана, поэтому наклонённые аппараты управляются согласованно.

У каждой планеты и каждого аппарата собственный сохранённый ракурс. В крупном плане вращается аппарат, фоновая планета продолжает независимое спокойное вращение. Размер модели нормируется по её габаритам с учётом антенн, лепестков, крышки и парашюта. Планета становится большим фрагментом поверхности, переход обратим от прокрутки.

Маркеры — экранные кнопки с областью 32×32 px на компьютере и 44×44 px на сенсорном экране. Проекция и проверка перекрытия скрывают задние точки. Видимые детали также доступны через компактное меню «Детали». Нажатое пояснение сохраняется до закрытия, Escape или смены этапа/модели. Карточка занимает отдельное место под моделью.

Сборка «Мира» завершается в первой части доступного последнего этапа; затем остаётся участок осмотра. Его прогресс учитывает момент освобождения sticky-сцены, а не только высоту текстовой статьи. Горизонтальных переходов и таймерной задержки прокрутки нет.

Проверки логики и геометрии: распакуйте `Проверки.zip` в корень проекта, затем выполните `node qa/pass5/verify.mjs` и `node qa/pass4/verify.mjs`. В полном локальном архиве папка `qa` уже присутствует. Публичный адрес: https://haist-pm.github.io/ussr-space/. GitHub Actions подтвердил сборку и развёртывание. Браузерная проверка пятого прохода отложена по просьбе пользователя; визуальная оценка и замеры производительности в браузере не выполнены. Подробности в `Проверка.md`.

## Запуск и сборка

Нужен Node.js 20+.

```sh
npm ci
npm run dev
```

После изменения исходников повторите сборку и обновите страницу.

```sh
npm run check
npm run build
node qa/pass3/verify.mjs
node qa/pass4/verify.mjs
npm run preview
```

`dev` и `preview` используют порт 4173. Для одновременной проверки: `PORT=4174 npm run preview`.

`dist/` содержит готовый статический сайт. `dist/Открыть-сайт.html` содержит встроенные скрипты, стили и текстуры — резервная автономная копия. Для просмотра 3D требуется WebGL; описание остаётся доступным при его отсутствии. Внешние исторические источники требуют интернета.

## Структура

- `index.html`, `app.js` — существующая экспозиция, исторический текст и интерактивы.
- `src/museum.js` — общий рендерер, Земля, управление, отрисовка, глубина и диагностика.
- `src/story-state.js` — независимое от времени вычисление этапов, переходов и сборки станции.
- `src/interaction.js` — поворот в осях экрана, кадрирование, проекция и выбор маркеров.
- `src/models.js` — геометрия аппаратов и пояснения деталей.
- `style.css` — композиция, адаптивность, доступность.
- `assets/` — локальные текстуры, лицензии и атрибуция.
- `build.mjs` — сборка esbuild и автономный HTML.
- `.github/workflows/pages.yml` — GitHub Actions: проверка, сборка, GitHub Pages.
- `Сценарий защиты.md`, `Проверка.md` — материалы для выступления и результаты проверки.

## Диагностика

Параметр `?qa=1` открывает панель проверки: фаза орбиты, этапы прокрутки, ручной поворот, число кадров и завершённых оборотов, ресурсы и GPU-проверка перекрытия. На обычной ссылке панель отсутствует. GPU-аудит сравнивает число пикселей спутника с Землёй и без неё на 6 сочетаниях ручного поворота планеты и фазы; рабочая сцена всегда использует настоящее тестирование глубины.

Перед защитой сохраните автономную копию, проверьте проектор, фамилии участников и отрепетируйте переходы. Схемы не следует называть фотографиями, посадку автомата — высадкой человека.

## Плавные переходы и звёзды — версия 5.0.0

Основной переход занимает 0,9 высоты окна (не менее 360 px), включая подготовку композиции и появление аппарата; соответствующий текстовый этап имеет минимальную длину 1,45 высоты окна. Планета, аппарат, камера и подписи используют общий прогресс прокрутки. Движение обратимо и не продолжает самостоятельно проигрываться после остановки страницы. При уменьшении окна камера сразу обеспечивает вписывание, при увеличении приближается с коротким сглаживанием.

Для посадки «Марса-3» используются две заранее рассчитанные композиции: масштаб и центр непрерывно интерполируются между ними, без пересчёта видимых габаритов каждый кадр.

Звёздное поле — один 2D-холст с максимумом 240 звёзд, ограничением 24 обновления в секунду и DPR 1,25. Закреплённые сцены копируют его пиксели, сохраняя рисунок за моделями и закрывая проходящий под ними текст. Отдельные звёзды в 3D-сценах удалены. Большинство точек статично; небольшая часть меняет яркость на ±12% с разными циклами 4–10 секунд. Общая пауза, скрытая вкладка и reduced motion останавливают мерцание. Фон не перехватывает указатель.
