# Проверка четвёртого прохода

4 октября 2026 года. Исправления выполнены в существующем проекте «ОРБИТА».

## Реализовано

- Единый глубокий фон `#070b10`: страница, шапка, маски WebGL, области чтения, подписи, мобильная версия, технологии, источники и итоги.
- Поворот по экранным осям: горизонтальное/вертикальное движение поверхности совпадает с мышью и стрелками. Инерция использует то же направление. Повороты не ограничены углами Эйлера.
- Раздельные состояния управления для планет и каждого аппарата. Пауза останавливает автоматическое движение, сохраняя ручное. Возврат ракурса влияет только на главный объект.
- Габариты аппаратов учитывают всю видимую геометрию. Центрирование и нормирование по охватывающей сфере обеспечивают запас до края кадра при поворотах. Планета в крупном плане увеличивается до фрагмента поверхности; до появления аппарата она смещается из его области.
- Переходы Луна/Луна-9/Луна/Луноход, Венера/Венера-9, Марс/Марс-3 и Салют-1/Мир вычисляются из прокрутки. Два сменяющихся аппарата не показываются одновременно. Парашют «Марса-3» плавно убирается при раскрытии лепестков.
- Последний этап «Мира» учитывает фактическую границу освобождения sticky-контейнера. «Квант-2» и «Кристалл» появляются последовательно; после завершения остаётся участок осмотра. Таймеров ожидания нет.
- Экранные маркеры имеют стабильные размеры: область 32×32 px / 44×44 px на сенсорных экранах. При пересечении выбирается ближайшая точка, при равном расстоянии — стабильный индекс. Есть наведение, выбранное состояние, клавиатурные кнопки и меню «Детали».
- Пояснения закрепляются по нажатию. Уход курсора их не закрывает; закрытие — кнопкой, Escape, сменой модели/этапа или уходом из сцены. Карточка занимает собственную область под моделью.

## Проверено программно

- `npm run check` и `npm run build`: синтаксис, сборка, синтаксис встроенных скриптов автономного HTML.
- `node qa/pass3/verify.mjs`: сохранены 17 источников и исторические массивы миссий/технологий, 24 текстовых этапа, внутренние якоря без дублей и пропущенных целей. Автономный HTML содержит все пять карт, шрифт, стили и скрипт.
- `node qa/pass4/verify.mjs`: 12 направлений/наклонов для поворота, 180 сочетаний моделей/ракурсов/пропорций видовой области (включая 390×135 для модели с открытой карточкой). Проверка проекции охватывающих габаритов подтверждает отсутствие выхода за кадр в этих случаях.
- Видимые маркеры проверены в исходном ракурсе всех девяти моделей; после разворота на 180° задние маркеры недоступны. Дополнительно проверены реальная преграда перед точкой и допустимое небольшое погружение точки в собственную поверхность.
- Сборка «Мира» завершена до освобождения сцены в пяти расчётных размерах, в том числе при высоте окна 540 и 568 px. Отдельно проверены 72 комбинации промежуточной сборки и ракурса: максимум нормализованной экранной координаты 0,707 при границе 1.
- 16 переходов проверены на непрерывность параметров и отсутствие одновременного отображения двух аппаратов. Геометрические объёмы аппарата и планеты не пересекаются при проверенных входах и выходах крупного плана.
- Сохранена математическая проверка перекрытия орбиты Землёй; рабочая сцена использует depth test. GPU-проверка в `?qa=1` адаптирована к раздельному управлению, но в этом проходе не запускалась.
- Результаты: `qa/pass4/logic-results.json`, `qa/pass4/preservation-results.json`.

## Публикация и доступ к браузеру

После входа пользователя обновления загружены через веб-интерфейс GitHub в `Haist-PM/ussr-space`, ветка `main`:
- `9d3593f` — страницы, фон, сборка и версия 4.0.0;
- `3ad5f1f` — модели, переходы, независимое управление и детали;
- `3239dc1` — локальные карты планет, шрифт и атрибуция.

GitHub Actions подтвердил успешные build и deploy: [запуск №5](https://github.com/Haist-PM/ussr-space/actions/runs/37207273599), длительность 1 минута 4 секунды. Обновлённая публичная версия: https://haist-pm.github.io/ussr-space/. Автономный HTML также создаётся этой сборкой. Первые две промежуточные сборки завершились ошибкой до окончания загрузки зависимых файлов; итоговая полная сборка прошла.

Браузерная проверка сайта не выполнена. Повторная попытка после предоставления доступа пользователем дала два конкретных отказа:
- адрес `file://` автономной копии запрещён инструментом, который разрешает только HTTP и HTTPS;
- публичный адрес `https://haist-pm.github.io` отклонён из-за сохранённого пользовательского запрета доступа к этому домену.

GitHub доступен и публикация подтверждена его интерфейсом; отказ относится к просмотру самого сайта. Обход запретов не выполнялся. Снимок подтверждения: `qa/pass4/publication-success.jpg`.

Поэтому визуальная цельность, реальные жесты мышью/пальцем, удержание карточек, GPU-окклюзия, мобильная компоновка, режим выступления и production-страница не отмечены как прошедшие браузерную проверку. Числа размеров выше относятся к математическим тестам Three.js, а не к скриншотам браузера. Четвёртый проход реализован, собран и опубликован; браузерная приёмка требует снятия сохранённого запрета доступа к домену.

## Оставшиеся ограничения

Модели и движение остаются художественными техническими реконструкциями. Нормирование размеров сохраняет читаемость аппаратов, а не физический масштаб относительно планеты. Маркеры доступны только с видимой стороны. Точные CAD-детали, физика стыковки и полётная аэродинамика не моделируются. Производительность на слабых устройствах и длинная сессия WebGL в этом проходе не измерялись.
